# Support

Graph Agent is community-supported experimental software.

- Use GitHub Discussions for setup help, design questions, and general usage.
- Use the appropriate issue template for reproducible bugs or feature proposals.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Before requesting help, review the README and documentation, search existing issues, and run `pnpm check`. Include your operating system, Node.js and pnpm versions, runtime mode, relevant logs with secrets removed, and a minimal reproduction.
